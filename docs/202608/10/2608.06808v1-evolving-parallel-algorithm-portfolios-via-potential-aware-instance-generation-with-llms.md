## 摘要
基于大语言模型的自动组合构建（LLM-ACP）在解决复杂组合优化问题的实际少样本场景中泛化能力较差。实例与算法协同进化框架通过用当前算法组合表现不佳的生成硬实例扩展训练数据集来增强泛化性，从而解决这一问题。然而，这种范式面临两个关键限制：评估实例硬度依赖于高质量的参考解，且单一生成模式限制了实例多样性。为克服这些限制，我们提出了潜力感知的实例与算法协同进化（PIAC）框架。我们的核心贡献有两点。首先，我们提出了潜力增益这一新指标，无需参考解即可估计泛化增益，其方法是对生成的算法进行扰动并评估其在生成的问题实例上的改进潜力。其次，PIAC利用大语言模型合成多样化的实例变异器，探索问题实例空间中更广阔的区域，从而增强组合的泛化能力。鉴于不同算法的扰动空间各异，我们在贪心构造、蚁群优化和引导局部搜索算法骨架上实例化了我们的框架。在旅行商问题（TSP）和带容量约束的车辆路径问题（CVRP）上跨六种不同数据分布的广泛评估表明，PIAC始终优于最先进的LLM-ACP基线，尤其针对TSP贪心构造组合实现了19.76%的相对改进。

## Abstract
The Automatic Construction of Portfolios via Large Language Models (LLM-ACP) suffers from poor generalization in practical few-shot scenarios when solving complex combinatorial optimization problems. Instance and algorithm co-evolution frameworks address this by expanding the training dataset with generated hard instances on which the current algorithm portfolio underperforms, thereby enhancing generalization. However, this paradigm faces two critical limitations: evaluating instance hardness relies on high-quality reference solutions, and single-mode generation patterns limit instance diversity. To overcome these limitations, we introduce the Potential-aware Instance and Algorithm Co-evolution (PIAC) framework. Our core contribution is twofold. First, we propose potential gain, a novel metric that eliminates the need for reference solutions. This metric estimates generalization gain by perturbing the generated algorithms and assessing their improvement potential on generated problem instances. Second, PIAC leverages LLMs to synthesize diverse instance mutators, exploring a broader region of the problem-instance space and thereby enhancing the portfolio's generalization capabilities. Given that perturbation spaces vary across different algorithms, we instantiate our framework on Greedy Constructive, Ant Colony Optimization, and Guided Local Search algorithmic backbones. Comprehensive evaluations on the Traveling Salesman Problem (TSP) and Capacitated Vehicle Routing Problem (CVRP) across six distinct data distributions demonstrate that PIAC consistently outperforms state-of-the-art LLM-ACP baselines, notably achieving a 19.76% relative improvement for TSP Greedy Constructive portfolios.

## 1. 核心问题与研究动机
- **背景**：并行算法组合（PAPs）通过并行运行多个互补算法来提升整体性能。自动化组合构建（ACP）传统上在固定参数空间中搜索，而近期基于大语言模型的 LLM-ACP 范式（如 EoH-S）将搜索空间扩展到开放的程序化启发式代码空间。
- **问题**：在实际少样本场景下，可用训练实例很少，现有 LLM-ACP 方法容易在有限训练集上过拟合，导致对未见数据分布泛化能力差。
- **已有解决思路**：实例与算法协同进化（如 CEPS、DACE）通过生成当前组合表现不佳的“硬实例”扩展训练集，以推动组合持续提升。但该范式有两个关键局限：
  1. 评估实例硬度依赖高质量参考解（如最优解），实际场景中难以获得；
  2. 实例生成通常使用固定、预设的算子，模式单一，多样性不足。
- **本文目标**：提出 PIAC 框架，用“潜力增益（potential gain）”替代参考解评估实例价值，并利用 LLM 合成多样化实例变异器，以扩大实例搜索空间，增强算法组合的泛化能力。

## 2. 方法论
- **核心思想**：将实例质量与算法组合的“改进潜力”联系起来，通过扰动算法启发式组件来估计改进空间；同时将实例生成视为程序化变异器上的进化搜索。
- **潜力增益（Potential Gain）**：
  - 对固定骨架 B 与 LLM 启发式 H 构成的算法 A = B[H]，在求解状态 s 下启发式输出矩阵 M = H(x, s)。
  - 引入乘性随机扰动：Pξ(M) = M ⊙ max(ε, 1 + E(ξ))，其中 E(ξ) 各元素独立服从 N(0, σ²)。
  - 将扰动后的启发式嵌入同一骨架得到扰动算法 Ã(ξ)。
  - 对当前组合 A 分配总扰动预算 Np 后，定义潜力增益：V(x; A) = (F(A, x) − F(Ã, x)) / F(Ã ∪ A, x)。若轻微扰动就能显著改进解，说明该实例暴露了组合决策边界的弱点，适合加入训练集。
- **LLM 驱动的实例生成**：
  - 维护一个变异器（mutator）种群，变异器是可由 LLM 生成的可执行代码，用于改造基础实例。
  - 变异器适应度定义为多次执行后生成实例的潜力增益平均值。
  - 每轮通过 LLM 对父变异器执行交叉与突变操作，生成子代变异器；从候选实例中选取潜力增益最高的 Top-Naug 个实例加入训练集。
- **LLM 驱动的算法组合构建**：
  - 初始化时用 LLM 生成候选算法池，通过贪心选择构建规模为 K 的初始组合。
  - 进化操作包括“互补操作”（配对互补父算法，由 LLM 生成兼顾两者优势的新算法）和“变异操作”（对单个算法进行结构扰动），并引入“反射”机制提供高层改进提示。
  - 组合维护采用贪心替换策略，仅当替换增益为正时才将新算法纳入组合，保持组合规模固定为 K。

- **算法骨架**：贪心构造（TSP、CVRP）、蚁群优化（TSP）、引导局部搜索（TSP）。
- **评估指标**：以最优间隙（Optimality Gap）衡量解质量，参考解由 LKH（TSP）和 HGS（CVRP）计算。

## 5. 主要结果与发现
- **总体性能**：在 TSP 与 CVRP 的全部六个数据分布上，PIAC 均取得最低平均最优间隙，显著优于 FunSearch、EoH、ReEvo、MCTS-AHD、EoH-S 等全部基线。在 TSP 上，PIAC 在 Rue、Explosion、Grid 等分布上的最优间隙相比最强基线 EoH-S 降低约 5%–15%；在 CVRP 上，优势在 Cluster 与 Expansion 分布上尤为明显。
- **跨分布泛化能力**：虽然训练实例仅来自 Rue 分布，PIAC 在未见过的 Explosion、Implosion、Expansion、Cluster、Grid 分布上依然保持领先，证明其具有较强的分布外泛化能力；相比之下，基线方法在远离训练分布的测试集上性能衰减显著。
- **公共基准表现**：在 TSPLib 与 CVRPLib 的 10 个公开基准子集上，PIAC 同样取得最优或次优的平均最优间隙，进一步验证其实例生成机制有助于发现通用性更强的算法组合，而非仅在合成分布上有效。
- **消融实验**：
  - PIAC 显著优于 PIAC(RND)，说明由 LLM 驱动的变异器进化是性能提升的关键因素；固定随机变异器无法为算法进化提供足够高质量的硬实例。
  - PIAC 显著优于 PIAC(GAP)，说明在缺乏高质量参考解的实际场景下，潜力增益相比传统最优间隙指标更能有效筛选有价值实例，且对参考解质量不敏感。
  - PIAC 与 PIAC(GAP) 的差距在 CVRP 上大于 TSP，作者推测是因为 CVRP 的参考解（HGS）更难达到全局最优，导致 GAP 指标噪声更大，而潜力增益不受参考解精度限制，稳健性更强。
- **机制分析**：
  - 潜力增益与真实泛化收益之间存在正相关：加入高潜力增益实例后，算法组合在测试集上的表现提升更明显，说明该指标能有效反映实例对组合进化的引导价值。
  - 变异器种群在进化过程中呈现多样性增长趋势，LLM 能够生成超出预设模板的复杂实例变换操作（如局部聚类扰动、坐标映射变形等），印证了开放程序化搜索空间相对固定实例算子的优势。
  - 生成的变异器在不同问题类型（TSP 与 CVRP）之间不具有迁移性，但在同问题不同分布之间存在一定迁移效果，作者据此认为实例生成阶段与算法进化阶段应当共适应，而非使用通用变异器库。

## 6. 核心贡献
1. **提出潜力增益指标**：不依赖任何外部参考解，仅通过启发性组件的随机扰动来量化实例对当前算法组合的改进空间，解决了少样本场景下实例硬度难以评估的问题。
2. **开创性引入 LLM 驱动的实例变异器进化**：将实例生成从固定算子扩展为开放的程序化搜索空间，通过进化变异器代码持续产出多样化硬实例，显著提高了实例集的覆盖度与多样性。
3. **构建实例–算法的双进化闭环**：算法组合进化利用生成的硬实例作为训练信号，而实例变异器进化反过来以算法组合的潜力增益为适应度，形成相互促进的协同进化机制，有效缓解少样本过拟合。
4. **系统验证 PIAC 的实际有效性**：通过跨分布、跨库、多骨架的全面实验，证明 PIAC 在 TSP 与 CVRP 上均显著超越现有 LLM-ACP 方法，且无需参考解，更贴近真实应用约束。

## 7. 局限性
- **问题域覆盖有限**：实验仅验证了组合优化中的两类经典问题（TSP、CVRP），未涉及调度、分配、图优化等其他组合优化问题，其通用性有待进一步验证。
- **算法骨架依赖预设**：PIAC 的潜力增益计算依赖于对具体算法骨架（贪心构造、ACO、GLS）的定制化扰动公式，骨架更换时需要重新设计扰动方式，推广成本较高。
- **LLM 调用成本与稳定性**：虽然论文未报告 API 总调用次数与成本，但每轮进化需要多次 LLM 推理（算法生成、变异器生成、反射），且依赖 DeepSeek 等商用模型，实际运行成本与响应延迟未被量化。
- **超参数敏感性**：扰动预算、噪声强度、变异器种群规模、每次迭代添加的实例数等超参数未做系统敏感性分析，其最优取值可能随问题规模或数据分布变化。
- **理论基础薄弱**：潜力增益的定义基于启发式且合理的直观假设，但缺少形式化的理论分析（如收敛性、泛化误差界），其有效性目前仅由实验支撑。

## 8. 未来研究方向
- 扩展到更多组合优化问题与算法骨架，建立自动化扰动生成机制以减少手工设计成本。
- 对潜力增益指标进行理论分析，刻画其与泛化误差、实例分布之间的关系。
- 探索更高效的 LLM 交互策略（如批量生成、缓存复用、蒸馏小模型）以降低运行成本。
- 研究变异器跨问题迁移的条件与机制，尝试构建可复用的实例变换先验知识库。
- 结合主动学习思想，在每轮进化中动态决定生成实例的数量、难度与多样性之间的权衡。

## 9. 个人评述
PIAC 的核心洞察在于将“实例价值”从“与最优解的差距”重新定义为“对当前组合的潜在改进空间”，这一视角转换在少样本与无参考解场景下极具实用意义。其将实例生成提升为与算法进化对等的搜索过程，并通过 LLM 实现开放代码空间的变异器进化，设计逻辑完整且实验结果有力。然而，潜力增益的计算需要通过多次带噪声扰动执行算法，计算开销较传统实例生成方法更高；此外，针对不同算法骨架的手工扰动公式限制了方法向更广泛算法体系的自动化扩展。总体而言，PIAC 在问题定义、方法设计、实验验证上均达到较高水准，是 LLM-ACP 方向上的一项扎实且有启发性的工作。
