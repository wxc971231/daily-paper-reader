## 摘要
大语言模型（LLMs）的快速发展为自动化启发式设计（AHD）求解NP难组合优化问题（COPs）开辟了新途径。然而，现有的LLM驱动的AHD方法大多局限于刚性求解器模板，将搜索过程降级为孤立的模块调优。转向完全自主的系统级算法设计至关重要，但面临生成算子可靠性低、搜索空间极大和信用分配无效等挑战。为克服这些缺点，本文提出了一种有向图引导的自动算法设计框架，称为DGA$_2$D。它将开放的程序空间构造为有向图，其中每个节点表示一个功能算子，可使用多个候选代码实现之一进行实例化，而有向行走构成完整的算法流程。引入了一种一阶路径相关的信用分配机制，以根据拓扑上下文严格评估代码变体。在从复杂调度到路由的12个不同COPs上的广泛实验证明了DGA$_2$D的一致实证优势。与最先进的LLM基线相比，平均归一化差距最多降低10.96个百分点。

## Abstract
The rapid development of Large Language Models (LLMs) has opened new avenues for Automated Heuristic Design (AHD) for solving NP-hard combinatorial optimization problems (COPs). However, existing LLM-driven AHD methods are largely confined to rigid solver templates, relegating the search process to isolated module tuning. Transitioning to fully autonomous, system-level algorithm design is essential but fraught with low reliability of generated operators, extremely large search spaces, and ineffective credit assignment. To overcome these drawbacks, this paper proposes a Directed Graph-Guided Automated Algorithm Design framework, termed DGA$_2$D. It structures the open-ended program space as a directed graph, where each node represents a functional operator that can be instantiated using one of multiple candidate code implementations, while directed walks constitute complete algorithmic pipelines. A first-order path-dependent credit assignment mechanism is introduced to evaluate code variations strictly based on their topological context. Extensive experiments across 12 distinct COPs, ranging from complex scheduling to routing, demonstrate the consistent empirical advantages of DGA$_2$D. It reduces the average normalized gap by up to 10.96 percentage points compared to state-of-the-art LLM baselines.

### 1. 论文的核心问题与整体含义

- **研究背景**：组合优化问题（COPs）广泛存在于实际工程与工业场景中（如柔性作业车间调度、车辆路径规划等），且大部分为NP-hard问题。不同问题需要定制化算法，而传统启发式算法设计高度依赖人力专家经验，成本高、可扩展性差。经典AHD（Automated Heuristic Design）虽尝试自动化，但仍受限于人工设计的模块与算子。
- **核心问题**：现有LLM驱动的AHD方法（如FunSearch、EoH等）大多在固定的求解器模板内做局部模块调优，本质上是"半自主"的。若要让LLM同时作为算法框架架构师和算子设计者，实现**完全自主的系统级算法设计**，则面临三大挑战：
    1. 生成算法的可靠性低（长算子序列易出现编译错误、接口不匹配、逻辑失败）；
    2. 搜索空间极大（开放程序空间中有效且高性能的算法非常稀疏）；

- **整体含义**：论文提出DGA₂D框架，将有向图作为算法搜索空间的表示，将整个算法设计过程从"孤立启发式优化"推进到"系统级算法演化"层面，为解决上述挑战提供了一种新的范式。

### 2. 论文提出的方法论

- **核心思想**：将算法搜索空间建模为**有向图（Directed Graph, DG）**，节点代表功能算子（可关联多个候选代码实现），有向路径（directed walks）代表完整的算法流程。LLM驱动三种操作完成演化：①编辑每个算子内部的实际代码；②重新排列算子间的连接（拓扑路径变化）；③为特定路径选择最合适的代码变体。
- **总体框架**：DGA₂D由四部分组成：
    1. **LLM基础初始化**：输入目标问题的自然语言描述，设置超参数空间（如最大算子数K、采样温度τ），并构建初始算子池（从已有算法和领域文献中由LLM筛选）。
    2. **图引导的候选算法构建**：将搜索空间表示为有向图D_t=(O_t, E_t)，每个算子O_i关联一个实现池C_i^(t)；每代采样N个有界有向路径作为管道P_t,j，再按实现选择概率为每个算子选择具体代码实现，形成候选算法A_t,j。
    3. **评估与信用分配**：
        - 算法级评估：在k个实例上计算方向感知归一化差距gap，得到适应度S_t,j；
        - 终端奖励：对适应度做标准化得到eR_t,j；
        - 管道级信用：通过策略梯度式损失L_pipe更新管道采样策略π_pipe；
        - 代码实现级信用：采用**一阶马尔可夫近似**，用Q_t(e)估计从上一实现到当前实现的转移的期望标准化终端奖励，更新公式为Q_{t+1}(e)=(1-α_t)Q_t(e)+α_t·eR_t,j；代码采样策略π_code基于Softmax(Q_t(e)/τ)。
    4. **信用引导的双层演化**：根据聚合信用，在算子实现层（删除/添加/替换最低信用算子的最差实现）和管道拓扑层（删除最低信用边并用LLM生成的新兼容边替代）同时进行演化。
- **关键公式**（文字说明）：
    - 归一化差距gap基于参考值（最优值或BKS）按优化方向计算；
    - 转移信用用指数移动平均更新（学习率α）；
    - 实现级信用、算子级信用和边级信用均为加权聚合形式。
- **一阶路径依赖**：论文通过定理严格证明了一阶上下文信用分配在有限样本下具有最优的偏差-方差权衡：零阶存在表示偏差，二阶及以上不减少零偏差但增加方差。

### 8. 不足与局限

- **计算成本**：DGA₂D的墙钟时间高于EoH、ReEvo和MEoH（因额外的策略搜索、信用分配和本地程序维护），虽然在LLM token上更省，但需要更多本地计算资源。
- **对初始算子池的敏感性**：性能受初始算子池质量影响，论文中虽做了K的敏感性分析，但未深入讨论算子池内容选择对最终结果的影响。
- **跨模块一致性风险**：系统级算法中不同算子间的接口兼容与逻辑一致性仍可能存在问题，论文仅依赖AST、签名、隔离运行和组合冒烟验证，复杂逻辑错误可能漏检。
- **LLM后端依赖**：虽然不同骨干下均有效，但性能绝对值仍受LLM能力影响（更强的后端通常得到更低的Gap）。

- **理论假设的理想性**：信用分配的统计理论分析基于同方差、条件不相关的理想化噪声模型；实际中同一候选算法的多个转移共享同一标准化奖励，样本间存在相关性，理论结论不能完全精确描述实际算法的有限样本风险。
- **实际工业部署验证不足**：未涉及真实生产环境的大规模应用，主要在公开基准实例上验证。
