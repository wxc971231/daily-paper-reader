## 摘要
在由语言模型驱动的进化算法中，LLM充当单一算子，同时更新结构组件（如控制流）和连续参数。虽然LLM可能擅长前者，但它们在后者上效率不高，会在试错循环中浪费令牌进行离散跳跃。我们通过形式化一种混合嵌套搜索来解决这一问题，其中外层循环让LLM提出带有数值间隙的结构草图，内层数值优化器则调整该草图。外层和内层求解器都是可插拔的：任何基于文本的优化器都可以与零阶优化器（如CMA-ES）、基于梯度的算法或MCMC采样器相结合。我们在三个科学领域验证了我们的框架：（i）闭式测试函数上的元优化器，（ii）用于系统研究和社会困境的基于代码的策略，以及（iii）近似贝叶斯推断任务。在所有三个领域中，混合优化器都优于纯LLM驱动的搜索和纯数值优化基线。代码见：https://github.com/vicgalle/hybrid-nested-search

## Abstract
In evolutionary algorithms powered by language models, the LLM acts as a single operator that simultaneously updates structural components (like control flow) and continuous parameters. While LLMs can be good at the first, they are not efficient at the second, wasting tokens taking discrete jumps inside a trial and error loop. We resolve this by formalizing a hybrid nested search, in which an outer loop has the LLM propose a structural sketch, with numeric gaps, and an inner numerical optimizer tunes the sketch. Both the outer and inner solvers are pluggable: any text-based optimizer can be combined with a zero-order optimizer (CMA-ES), gradient-based routines, or MCMC samplers. We validate our framework across three scientific domains: (i) meta-optimizers on closed-form test functions, (ii) code-based policies for systems research and social dilemmas; and (iii) approximate Bayesian inference tasks. Across all three, the hybrid optimizer is superior to both vanilla LLM-driven search and pure numerical optimization baselines. Code at: https://github.com/vicgalle/hybrid-nested-search

## 1. 核心问题与整体含义（研究动机与背景）

- **问题根源**：在以语言模型（LLM）驱动的进化算法中，LLM 被当作单个算子同时完成两类截然不同的优化任务：
  - **结构层面**：程序拓扑、控制流、函数定义等离散文本结构；
  - **参数层面**：阈值、学习率等连续数值。
- **核心矛盾**：LLM 在结构搜索上拥有先验知识、表现较好，但在连续参数优化上效率很低——它通过离散试错进行跳跃式搜索，浪费大量 token 和算力。
- **已有方案缺陷**：现有 LLM 驱动的科学发现系统（如 FunSearch、AlphaEvolve 等）均采用“vanilla autoresearch”模式，即让 LLM 在一次优化回合中同时生成完整工件（结构+参数），因而继承了这一效率缺陷。
- **论文的核心主张**：应将一个工件（优化解）分解为两种性质不同的决策类型——结构（文本型，适合 LLM）与参数（连续黑箱优化，应交给专门的数值求解器）——并形式化为一个嵌套搜索框架。

## 2. 提出的方法论：混合嵌套搜索（Hybrid Nested Search）

### 2.1 核心思想
将优化问题表示为**双层目标**：
- **外层**：冻结的 LLM 作为结构提议算子，生成带数值间隙的结构草图（sketch）τ；
- **内层**：可插拔的数值优化器（CMA-ES、梯度法、MCMC）在给定结构 τ 下优化参数 θ 至其参数最优值 θ*(τ)；
- 结构仅在其**调优后**的适应度 bF(τ) ≈ maxθ f(τ,θ) 上被评分和保留。

### 2.2 关键概念与公式
- **草图分解（Sketch Decomposition）**：候选程序为 ⟨τ, θ⟩，结构 τ 暴露 h(τ) 个数值空洞；实例化映射 Inst(τ, θ) 将空洞填充为可执行代码。
- **参数清单（Parameter Manifest）**：LLM 为每个空洞输出元组 (j, ℓⱼ, uⱼ, typeⱼ, θ̄ⱼ)，给出下界、上界、类型（cont/int/log/pow2）和建议值 θ̄，作为内层优化器的热启动。
- **双层目标**：
  - 内层：F(τ) = max_{θ∈Θ(τ)} f(τ, θ)，θ*(τ) = argmax f(τ, θ)；
  - 外层：τ* = argmax_{τ∈T} F(τ)。
- **算法流程（Algorithm 1，(1+1) 式外层循环）**：
  1. LLM 提议初始结构 τ₀ + manifest m₀；
  2. 内层 Tune 在预算 B_in 内优化参数，返回 bF₀ 和 θ*₀；
  3. 设定初始最优解；
  4. 迭代 K 轮：LLM 基于前一轮的最优结构、调优后的适应度、最优参数和诊断信息突变产生新结构 τₖ；
  5. 若 τₖ 通过 Validate 检查，则调用内层 Tune 得到 bFₖ、θ*ₖ；
  6. 若 bFₖ > V*，则提升为新的最优解并返回。

### 2.3 参数去混淆（Parametric De-aliasing）——核心理论贡献
- **定义参数调优间隙**：Δ(τ) = F(τ) − f(τ, θ̄(τ)) ≥ 0，即结构在 LLM 猜测参数下被浪费的潜在适应度。
- **Proposition 1** 的三个推论：
  1. 当且仅当 Δ(τ) − Δ(τ′) 不翻转 F(τ) − F(τ′) 的符号时，vanilla 与 hybrid 产生相同偏好；
  2. Vanilla 搜索可能丢弃结构最优 τ* 而保留较差 τ′；Hybrid 在 2ε 误差范围内不会犯此错误；
  3. 在 F ⊥ Δ 假设下，混合搜索的优势可分解为“选择项”（在翻转处为正）与“调优项”（对每个被接受结构恒正），两者都随 E[Δ] 与 Var(Δ) 增大而增大；当 Δ ≡ 0 时优势消失。
- **可证伪的预测**：(hybrid advantage) ∝ E_{τ∼M}[Δ(τ)]，这是贯穿全文三大实验域的验证主线。

### 2.4 成本分析
- 总成本：C_hyb = K(c_llm + B_in·c_ev)；C_van = K·c_llm。
- 实际场景中，LLM 调用（分钟级）远贵于单次评估（秒级），c_ev/c_llm ≈ 10⁻²~10⁻³，因此 B_in ≈ 100 时仅增加 10–100% 开销，却充分利用了每次昂贵的 LLM 提议。
- 对评估昂贵的领域（如每次评估是一次完整训练）需更换内层求解器（如贝叶斯推断场景中使用 VI 或 NUTS 的 warmup）。

## 6. 主要结论与发现

1. **混合嵌套搜索全面优于两种基线**：在三大领域（元优化、策略、推断）的所有非平凡场景中，Hybrid 均优于 vanilla LLM 搜索与纯数值优化基线。
2. **参数去混淆（de-aliasing）是核心机制**：Hybrid 让结构在“参数最优值”而非“LLM 猜测值”上被评分，避免了好结构因默认参数差而被误删的问题。
3. **预测性理论得到验证**：混合优势 ∝ E[Δ]，两列数据的相关性在多个任务中被观察到（Cleanup 最强、Cloudcast 次之）。
4. **可插拔性与正交性**：内层求解器（CMA-ES/VI/NUTS）与外层优化器（(1+1) LLM / GEPA）均可任意替换，结论保持定性不变；更强的外层优化器会缩小但不会反转混合参数化的边际收益。
5. **发现了一个显著的共同天花板现象**：在 Cleanup 重难度下，三个不同模型独立收敛到同一算法族（死区+斜坡+饱和上限），且调优后福利相同（0.582）——结构多样性收敛在调优后的空间中显现。
6. **贝叶斯推断中的洞见**：NUTS warmup 已线性预条件化，因此仿射重参数化对 NUTS 冗余（Δ≈0、平局）；而 VI 固定标准 guide 则需要重参数化承载全部位置/尺度，非线性几何（funnel、eight_schools、banana）无法被任何质量矩阵修复，混合搜索的增益显著。

## 7. 优点

- **概念清晰、形式化完备**：将“结构 vs 参数”这一直觉，形式化为双层优化 + manifest 接口 + 参数去混淆的严格理论（Proposition 1 有完整证明），并提供可证伪的定量预测。
- **高度可插拔的通用框架**：内外求解器均可替换，支持零阶（CMA-ES）、一阶（梯度法）与采样法（MCMC/VI）多种内层求解器，并能在 NUTS 内层下与 NeuTra 式管道组合。
- **跨域验证充分**：从闭式函数、仿真系统策略到贝叶斯推断的远程测试，构建了广泛的证据链。
- **理论与实验闭环**：每个领域都直接测量 E[Δ] 并对照混合优势，使理论预测与实验观察一致可见。
- **工程细节扎实**：manifest 的多种数值类型（cont/int/log/pow2）、热启动、验证过滤、SBC 参考自由校验、held-out 评估门控等设计体现了严谨性。
- **发现真实且可复现的算法模式**：附录 C 展示的一组代码工件（Nesterov+cosine+clipping、周期性随机重启、磁滞控制器、自共享 Steiner 树、非线性二次剪切、部分非中心化等）揭示了“结构由 LLM 创造、常数由数值求解器决定”的可复现模式，极具启发性。
- **诚实的局限讨论**：明确指出 No Free Lunch 约束、参数维度上限、新颖性天花板等，避免了过度宣称。

- **新颖性天花板**：方法依赖 LLM 检索已有结构惯用语（如非中心化、Nesterov、Steiner 树等），对于真正的全新结构发现能力有限，论文也承认更适合人类在环的 copilot 模式而非全自主系统；
- **E[Δ] 预测的边界情况**：ellipsoid 上 E[Δ] 大但实际优势为零（两个臂都收敛到机器精度）、Can't Be Late 的 E[Δ] 顺序与工程难度不单调，说明 Δ 并非唯一的预测因子，理论中的独立假设（F ⊥ Δ）在现实中可能被违背；
- **SBC 门控的局限**：SBC 本身依赖正确先验和足够样本，论文虽用 Bonferroni 校正但仍无法保证在所有失败模式上有效。
