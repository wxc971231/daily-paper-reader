## 摘要
LLM提示词和智能体程序（如GEPA）的进化优化主要由适应度评估主导：对每个候选者进行评分需要对验证集运行一个回答LLM，因此评估者的价格层级决定了总搜索成本。我们通过解耦LLM扮演的三种角色来重构该搜索过程：将高容量的回答角色放在最便宜的层级，保留强模型用于罕见的反思/变异算子，然后利用向上的跨层迁移将廉价进化得到的提示词部署到更强的目标模型上。我们贡献了一种成本受控的表征，说明何时廉价层级搜索可以替代目标层级搜索，以及何时会失败。在四个任务（HotpotQA、IFBench、LiveBench-Math、HoVer）和四个模型家族的十一个模型上，所得提示词匹配或超过了同层优化，同时将超过96%的搜索token置于最廉价层级，搜索成本降低5.6-14倍，在推理层级每次适应度调用都产生长思维链的情况下，成本降低可达25-54倍。

## Abstract
Evolutionary optimization of LLM prompts and agentic programs (e.g., GEPA) is dominated by fitness evaluation: scoring each candidate runs an answering LLM over a validation set, so the evaluator's price tier dictates total search cost. We restructure that search by decoupling the three roles an LLM plays, running the high-volume answering role on the cheapest tier, reserving a strong model for the rare reflection/variation operator, then exploiting upward cross-tier transfer to deploy the cheaply evolved prompt on a stronger target. We contribute a cost-controlled characterization of when cheap-tier search substitutes for target-tier search, and where it fails. Across four tasks (HotpotQA, IFBench, LiveBench-Math, HoVer) and eleven models in four model families, the resulting prompt matches or exceeds same-tier optimization while placing over 96% of search tokens on the cheapest tier, at 5.6-14x lower search cost, rising to 25-54x where reasoning tiers emit long chains of thought on every fitness call.

## 1. 论文的核心问题与整体含义

进化优化（Evolutionary Computation）在 LLM 提示词与智能体程序优化中已成为一种有效方法（代表如 GEPA），但其核心瓶颈在于**适应度评估成本**：每个候选提示词都需要在验证集上调用一次“回答 LLM”打分，评估者的价格层级直接决定了整个搜索过程的成本。传统做法强制 `M_answer = M_reflect = M_deploy`（即搜索、变异与部署使用同一个模型），使得优化一个强模型时整个搜索都必须在该强模型上运行，极大限制了种群规模、进化代数与最终质量。

本文提出一个简单但关键的问题：**搜索过程是否必须运行在目标部署模型上？** 答案是**否**。作者将 LLM 在进化循环中的三种角色——**评估（answering）、变异（reflection/variation）、部署（deployment）**——解耦，分别选择不同价格层级：高频评估由最廉价模型承担，低频但关键的变异算子由强模型执行，最终将廉价进化出的提示词零样本部署到更强的目标模型上。系统性研究表明这一策略在质量上不输同层完全优化的结果，而代价仅是后者的一小部分，从而把搜索成本从“目标模型的档次”中解放出来。

## 2. 论文提出的方法论

### 核心思想
将 LLM 在进化搜索中扮演的三个角色拆分到不同价格层级，利用**智能不对称性**：变异算子需要高精度、理解执行轨迹并重写提示词，这要求强模型且调用次数极少；而评估只需对候选者进行足够好的排名，不强求精确估计候选者的真实部署质量，因此廉价且噪声较大的评估器在绝大多数比较中已足够。二者形成互补而非妥协。

### 关键技术细节

1. **廉价适应度层（Cheap fitness tier）**：每个候选提示词都用最便宜的回答模型在完整验证集上评分。廉价模型不是待校准的数学代理模型，而是搜索期间的实际执行环境，从而将成本模型中的主导项压至最小。

2. **强变异算子（Strong variation operator）**：由强反射模型读取廉价模型生成的执行轨迹并编写针对性编辑。其可负担性来自**音量不对称**——反射调用次数极少（占全部调用不到 5%），虽然单次费用高昂，但总成本有界。

3. **向上跨层部署（Upward cross-tier deployment）**：最终提示词零样本部署在目标层（`M_dep ≥ M_task`），无需映射、校准或重新优化，一次搜索即可摊销到任意多个部署层。

### 成本模型公式

- 复合 AI 系统 Φ 的期望得分：`J_T(Π, Θ) = E_{(x,m)∼T}[μ(Φ(x; ⟨Π, Θ⟩_Φ), m)]`
- 优化目标：在 rollout 预算 B 下最大化 `J_T(Π, Θ)`
- 拆分后：`J_dep(Π) = J_task(Π) + Δ(Π)`，其中 `Δ(Π) := J_dep(Π) − J_task(Π)` 为跨层迁移残差
- 总成本近似为：

```
C_opt ≈ (KN_val + 2Ab)·c(M_task)  ← 适应度评估（主导）
       + A·c(M_refl)              ← 变异（罕见，token 密集）
```

其中 `N_val` 为验证集规模，`K` 为通过筛选的候选数，`A` 为尝试的变异数，`b` 为小批量大小。由于 `KN_val ≫ 2Ab`，评估层级决定总预算；将 `M_task` 压到最低层级即可大幅削减主导项。

### 两个待检验假设
- **零样本迁移（弱假说）**：`R_{s→t} ≈ 0`，即廉价进化提示词在部署模型上接近最优；
- **零样本正迁移（强假说）**：`R_{s→t} < 0`，即它优于目标层自己优化的提示词。

1. **质量与成本兼得**：廉价搜索在 48 个部署点中 36 个达到或超过同层完全优化，最多只差 3.8 个百分点，搜索成本降低 5.6–14×（Mixed Claude 与 GPT 家族）及 25–54×（Gemini，因推理层每轮都产生长思维链）。零 API 成本的 Qwen3-8B 可将账单压缩至仅反射器费用（每轮 <$2），仍匹配各付费层自己的完全优化。

## 7. 优点

- **清晰的问题重构**：将“目标层成本”转化为“自由参数”，以三角色解耦实现成本-质量权衡的结构化表征；
- **方法论上的严谨消融**：2×2 角色消融、跨优化器验证（GEPA vs MIPROv2）、跨反射器家族测试，层层剥离变量，定位真实机制；
- **全维度实验覆盖**：四类任务、三个独立定价体系、十一个模型，加上零成本极限测试，使结论具有很强的外部效度；

- **指标与成本分离测量**：token 计数与价格解耦，任何未来价格表都可直接重算，无需重跑实验；
- **可解释的迁移机制**：从提示显式性特征到反射器角色定位，给出了可验证的因果关系解释。

## 8. 不足与局限

- **对廉价层基线能力敏感**：若廉价模型在任务上接近 0 分，适应度地形平坦（无梯度、无 traceback、无选择压力），搜索停滞。方法仅在下限以上成立；
- **低头room 部署层无收益**：在提示不敏感的层级（如 LiveBench-Math 和部分 IFBench@luna），种子提示已接近所有优化方法，优化本身无增益空间——这是进化提示优化的通用限制而非本方法独有；
- **依赖价格表结构**：结论要求提供商确实提供分层定价体系，且当前收益以 0.04–0.25 的差价为基础；若差价大幅收窄（但 λ* 显示即使价格平价，15/24 单元仍更便宜），结论可能改变；
