## 摘要
我们考虑二元指示变量控制连续变量的混合整数凸优化问题。我们引入了坐标最优性重构（CORe）框架，该框架通过纳入逐坐标最优性信息来增强标准指示变量公式。所得重构在保持全局最优性的同时，显著提高了分支定界性能，尤其是在稀疏和结构化设置中，逐坐标最优性条件暴露了可利用的问题结构。我们首先发展了CORe的主要组成部分，包括逐坐标最优性条件、闭式特征描述和析取重构。然后，我们在多个问题族中展示了该框架，包括二次问题和稳健单指数模型。计算实验表明，与标准大-M公式相比，CORe可以显著提高求解器性能。

## Abstract
We consider mixed-integer convex optimization problems in which binary indicators control continuous variables. We introduce the \emph{Coordinate Optimality Reformulation} (CORe) framework, which augments standard indicator formulations by incorporating coordinate-wise optimality information. The resulting reformulations preserve global optimality while substantially improving branch-and-bound performance, particularly in sparse and structured settings where the coordinate-wise optimality conditions expose exploitable problem structure. We first develop the main components of CORe, including coordinate-wise optimality conditions, closed-form characterizations, and disjunctive reformulations. We then demonstrate the framework across multiple problem families, including quadratic problems and robust single-index models. Computational experiments show that CORe can substantially improve solver performance compared with standard big-$M$ formulations.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究对象**：一类混合整数凸优化问题，其中二元指示变量（0-1变量）控制连续变量的“激活/关闭”状态。典型形式为：
  - 目标函数为凸函数加线性惩罚项（对激活变量收取成本）；
  - 约束条件为 `x_i(1-z_i)=0`，即当 `z_i=0` 时强制 `x_i=0`；
  - 该类问题涵盖稀疏回归、鲁棒回归、图模型学习、单位承诺、异常值检测等众多应用。
- **现有瓶颈**：标准 big-M 公式虽通用，但连续松弛弱、预求解难以识别激活状态、分支定界需要探索大量次优激活模式，求解效率低。
- **核心问题**：能否在不损失全局最优性的前提下，通过引入坐标级最优性信息，增强混合整数公式的结构可解释性和剪枝能力？
- **整体含义**：论文提出 CORe（Coordinate Optimality Reformulation）框架，为指示变量约束问题提供了一套通用的、基于坐标最优性的公式强化原理，在多个问题族上显著提升分支定界求解器性能，并给出了若干结构化图类上的多项式复杂度保证。

### 2. 方法论：CORe 框架

**核心思想**：固定其他变量 `(x_{-i}, y)` 时，每个坐标 `(x_i, z_i)` 构成一维子问题。比较“关闭”（`z_i=0, x_i=0`）和“开启”（`z_i=1`，自由优化）两个状态的最优值，即可获得全局最优解必须满足的坐标级最优性条件。这些条件以约束形式编码进原问题，可剔除不可能出现在全局最优中的激活模式，同时保留所有全局最优解。

**三个核心组成部分**：

1. **最优性条件（OC）重构**：
   - 对每个坐标 i，定义关闭域 `D^0_i,OC` 和开启域 `D^1_i,OC`；
   - 关闭域要求 `x_i=0` 且开启不会改善目标；
   - 开启域要求坐标级驻点条件（`0 ∈ ∂_{x_i} f_i`）且开启不比关闭差；
   - 最终形式为析取约束 `(x,y,z) ∈ D^0_i,OC ∪ D^1_i,OC`。

2. **闭式（CF）重构**：
   - 当坐标最小化有闭式解 `x_i^* = x_i^*(x_{-i}, y)` 时，用显式等式 `x_i = x_i^*(x_{-i}, y)` 替代隐式一阶条件；
   - 例如二次规划中 `x_i^* = -g_i/Q_{ii}`，其中 `g_i = c_i + Σ_{j≠i} Q_{ij}x_j`。

3. **析取重构**：
   - 将 OC/CF 条件下的每个域表示成多面体，通过析取规划引入辅助变量和线性约束，形成闭式混合整数线性表达式；
   - 例如在二次规划中，每个坐标形成一个三域析取（负阈值域、关闭域、正阈值域），编码为线性约束组（公式 7–10）。

**关键数学结果**：
- 坐标级阈值规则：对二次规划，`z_i=0 ⇒ |g_i| ≤ τ_i`，`z_i=1 ⇒ |g_i| ≥ τ_i`，其中 `τ_i = √(2λ_i Q_ii)`。该阈值显式地将惩罚参数与坐标最优性关联起来。
- 正则化角色：增大 `λ_i` 会扩大关闭域 `|g_i| ≤ τ_i`，使 CORe 条件更有信息量，因此在强正则化设置下 CORe 优势更显著。

**复杂度保证**：
- **星图**：叶坐标的激活状态由中心节点单变量控制，分支定界树大小为 `O(n)`；
- **不平衡二分图（m 个中心变量）**：坐标阈值构成 m 维超平面排布，分支定界树大小为 `O(n^{m+1})`（m 固定时多项式）；
- **鲁棒单指数模型（d 个协变量）**：同样得到 `O(n^{d+1})` 节点界；
- **路径图**：存在对抗性实例使分支定界树指数增长（命题 3），但随机路径实例上 CORe 仍几乎根节点求解。

### 6. 主要结论与发现

1. **CORe 显著优于 big-M**：在所有测试的稀疏二次规划实例中，CORe 解到最优的节点数比原始公式少 2–6 个数量级，大量实例几乎在根节点解决。
2. **稀疏度是 CORe 发挥优势的关键**：δ 从 0.01 增至 0.50 时，CORe 的根间隙从 0 增至 51.6%，但仍远优于 big-M。
3. **正则化强度与 CORe 正相关**：惩罚参数增大（解更稀疏）时，CORe 从超时（最终间隙 5.3%）变为单节点最优解；big-M 基本不受影响。
4. **结构化图类上 CORe 可匹敌/超越专用算法**：在路径图（n=10000）上，CORe 用时 2.44s 优于参数算法的 8.19s；在树图上同样占优；星图（n=10000）CORe 用时 7.31s 对参数算法的 179.03s。
5. **最坏情形存在但非典型**：对抗性路径实例（τ 接近边界）可使 CORe 超时，暴露指数节点数；但随机路径实例几乎根节点求解。
6. **CORe 适用于非线性模型**：鲁棒逻辑回归中 CORe 最终间隙远低于 big-M（如 n=200 时 <0.5% vs. >30%），即使根间隙仍大，子问题质量显著更高。
7. **2D-GMRF 上 CORe 保持高性能**：n=1600、σ²=0.05 时，CORe 0.17s 求解，而 big-M 需 1982s 和 2M+ 节点。

### 7. 优点

- **统一性**：CORe 给出了一个通用原理，可同时适用于二次规划、鲁棒单指数模型、不平衡二分结构等多种问题族，而非单一专用算法。
- **最优性保持**：所有重构均不丢失全局最优解，具有严格理论保证。
- **理论复杂度**：在星图、不平衡二分图、鲁棒单指数模型等结构上给出多项式分支定界节点界，并指出路径图最坏情形的指数复杂度，理论刻画透彻。
- **求解器友好**：CORe 的附加约束为线性/凸约束，可直接嵌入商业 MIP 求解器，无需专门算法或求解框架。
- **实验覆盖面广**：从合成到真实数据、从二次到非二次、从随机图到结构化图类，验证了方法和普适性。
- **正则化-阈值解释**：揭示了惩罚参数如何通过阈值 τ 影响坐标级剪枝，为稀疏学习提供了直观而深刻的机理。

### 8. 不足与局限

- **稠密图性能退化**：随着图密度增加，CORe 的根间隙和节点数显著增长（δ=0.5 时需 2 万+节点、数百秒），说明局部坐标条件在高耦合时信息量有限。
- **路径图最坏情形**：存在使分支定界指数增长的对抗性结构（τ 临界时），理论保证不是全类通用。
- **鲁棒单指数模型效果有限**：由于闭式坐标最小化不可用（非线性链接函数），只能使用 OC 重构而无法使用 CF 强化；根间隙仍很大，最终间隙虽然远好于 big-M 但仍不够理想。
- **真实数据验证不足**：除加速计数据和乳腺癌数据集外，其余均为合成数据；真实领域（如基因调控、金融组合）未验证。
- **无消融实验**：OC 单独、CF 单独、析取重构各自的贡献未被量化剥离；参数敏感性（如 big-M 收紧方式、分支规则）也未系统研究。
- **算力报告不完整**：未报告 GPU/多机等，也不涉及大规模分布式求解场景；单机 8 核 CPU 配置下，大规模实例（n=10000+）的扩展性尚待验证。
- **应用限制**：当坐标间耦合强（稠密 Q）或坐标最小化无闭式解/不可凸化时，CORe 的优势可能被模型规模扩大带来的松弛求解开销抵消。
