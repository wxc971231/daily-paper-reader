## 摘要
大邻域搜索通常随机选择决策变量的子集进行迭代优化。为了高效解决各种问题，研究者倾向于设计考虑跨领域结构特征的变量选择策略。在本文中，我们构建了一个自动流水线，该流水线对MiniZinc格式的所有问题均与具体问题无关。通过用我们的语义指南提示LLM，我们引导LLM生成一个图生成器，该生成器将任何问题类型的实例映射为统一的加权图，其中节点表示决策变量，边表示约束关系。这些与问题无关的图指导我们基于结构的局部改进（SLIM）框架进行变量选择。同时，加权图使得所有问题实例共享相同的通用图表示，从中可以提取相同的图特征并用于配置选择。我们在20个MiniZinc竞赛问题的实例上评估了我们的流水线，发现算法选择相对于一次性Gurobi基线达到了39.6%的平均问题加权胜率，是最佳单一配置（19.3%）的两倍多。事后配置和特征消融表明有高达44.0%的提升空间，证明了基于LLM的语义生成能够为约束优化实现有效的自动化结构和特征提取。

## Abstract
Large neighborhood search normally selects a random subset of decision variables for iterative optimization. To efficiently solve various problems, researchers tend to design variable selection strategies that take into account structural features across different domains. In this paper, we build an automatic pipeline that is problem-agnostic to all problems in the MiniZinc format. By prompting an LLM with our semantic guidelines, we guide the LLM to produce a graph generator that maps any instance of a problem type to a uniform weighted graph, where nodes represent decision variables and edges represent constraint relationships. These problem-agnostic graphs guide our structure-based local improvement (SLIM) framework for variable selection. Meanwhile, the weighted graph enables all problem instances to share the same generic graph representation, from which the same graph features can be extracted and used for configuration selection. We evaluated our pipeline on instances across 20 MiniZinc competition problems, finding that algorithm selection achieves a 39.6% average problem-weighted win rate against a one-shot Gurobi baseline, more than doubling the best single configuration (19.3%). A post-hoc configuration and a feature ablation indicate a headroom of up to 44.0%, demonstrating that LLM-based semantic generation enables effective automated structure and feature extraction for constraint optimization.

## 1. 核心问题与研究动机

- **背景**：大规模邻域搜索（LNS）是处理复杂组合优化问题的重要元启发式方法，其核心是在每轮迭代中选择一部分决策变量进行局部优化。传统方法常采用随机变量选择，虽然计算廉价，但忽略了问题结构与实例特征，导致求解效率低下。
- **关键挑战**：设计结构感知的变量选择策略（即结构化的局部改进方法，SLIM）通常依赖领域专家对不同问题手工设计大量策略，工程量大、周期长，难以跨问题复用。
- **核心问题**：能否自动化地为不同约束优化问题生成结构化信息，并基于统一表示指导变量选择与算法配置选择，从而减少专家干预？

## 2. 方法论

- **总体思想**：构建一个自动流水线，利用大语言模型（LLM）将 MiniZinc 约束模型“编译”为图生成器（graph generator），把任意实例映射为统一的加权图，进而驱动与问题无关的 SLIM 框架和跨问题算法选择。
- **图表示**：
  - **节点**：对应决策变量，附带两个属性——重要性权重 \(w \in [0,1]\) 和域大小 \(d \in \mathbb{N}\)。
  - **边**：表示变量之间的约束关系，权重 \(w \in [0,1]\) 反映耦合强度。
  - 该表示完全脱离具体问题语义，所有问题实例共享同一种图格式。
- **LLM 生成指南**（语义规则）：
  1. 与目标函数相关的变量/约束赋予较高权重（≥0.6）；
  2. 大型全局约束（如 alldifferent）使用较低的边权（\(max(0.1, 1/n)\)，n 为变量数），避免形成“团”导致选择偏好失衡；小约束（n ≤ 5）保留强耦合（≥0.8）；
  3. 不允许孤立节点，确保每个变量都有可能被选中进入优化范围；
  4. 权重有界：多条相同边权重按 \(W = 1 - \prod_i(1-w_i)\) 聚合，保证最终权值不超过 1。
- **SLIM 框架**：
  - 基于统一图进行**提取操作**，两种提取策略：
    - **BFS 提取**：从按节点权重随机选取的起点出发，按边权偏置的随机顺序扩展邻域，保留局部结构；
    - **LNS 提取**：直接按节点权重随机收集变量，不考虑局部连通性。
  - 提取过程受**预算参数**控制（域大小感知的阈值），并支持“冻结模式”（选择变量作为冻结集合而非优化集合）。
  - 每轮迭代中：固定邻域外变量，用精确求解器优化局部子问题（加入目标不劣于当前最优的约束），用更好的解更新全局解；循环直到总时间或迭代次数上限。
- **算法选择**：
  - 从统一图中提取 54 维特征（拓扑统计、节点/边权重分布、域大小统计与相关性、实例元数据等），训练多输出随机森林回归模型，预测 30 种 SLIM 配置的改进幅度，选择最优配置。
  - 使用问题加权样本，避免实例数量不平衡（如 RCPSP 占 38%）造成偏差。
  - 共设计 5 种选择方法：回归、集成、二分类、多分类、两阶段。

## 3. 实验设计

- **数据集**：来自 MiniZinc 竞赛（2008–2025）的实例，满足以下筛选条件：
  1. Gurobi 能在 10 分钟内找到可行解但无法在 60 分钟内证明最优；
  2. 每个问题至少 5 个合格实例。最终得到 **20 个问题类型**，如 tdtsp、spot5、rcpsp、vrp、jobshop、opd 等。
- **基准**：
  - 基线为**一次性 Gurobi**（总时间 60 分钟）；
  - 对比对象：**最佳单一 SLIM 配置**、**虚拟最优（virtual best）** 以及 5 种算法选择方法。
- **配置空间**：30 种配置，包括预算 \(b \in \{10,20,50,70,100,200\}\)、超时 \(t \in \{20,30,45,60\}\) 秒以及不同提取策略。
- **评估指标**：问题加权胜率（win rate）、平局/失败率，每个实验使用 3 个随机种子（51, 52, 53）。
- **划分**：训练/测试按问题类型分层，70:30 比例。

## 6. 主要结论与发现

- **问题无关的 SLIM 有效**：使用 LLM 生成的图，配合简单的 BFS/LNS 提取策略，在 20 个问题中大部分问题的解质量优于一次性 Gurobi，例如 tdtsp、spot5、community-detection、triangular、opd 的胜率超过 75%；仅在 rectangle-packing 和 VRP 上胜率低于 50%。
- **算法选择显著提升**：最佳单一配置平均胜率约 19.3%，而 5 种算法选择方法达到 31%~40.6%；其中回归和集成方法在多数种子上表现最好，二分类方法最稳定。
- **潜力上限**：事后消融显示如果进一步裁剪配置与特征，胜率可提升至 44.0%，说明现有选择模型仍有改进空间。
- **LLM 语义提取有效**：证明了 LLM 能够将约束语义转化为图权信息，无需领域专家手工设计，即可支持跨问题自动化结构提取与配置选择。

## 7. 优点

- **高度自动化**：一次性 LLM 生成，即可用于所有 MiniZinc 实例，免去专家手工设计 SLIM 的大量工作。
- **问题无关的均匀表示**：统一加权图使特征提取、配置选择、局部搜索逻辑完全解耦，便于跨 20 个异构问题复用同一套方法。
- **泛化性强**：与以往针对单一问题的神经 LNS 和 portfolio 方法不同，该方法无需针对每个问题重新训练。
- **可审计与确定性**：LLM 生成的程序是确定性的，可验证、可复现，避免了端到端黑盒模型的不确定性。
- **实验覆盖面广**：20 个问题、数十种实例类型、30 种配置、3 种子、5 种选择方法，结果可信度较高。

## 8. 不足与局限

- **LLM 生成的近似性**：图生成器本质上是对真实约束语义的 LLM 近似，未经过严格数学保证，可能导致部分问题上结构信息失真（如 rectangle-packing、VRP 上 SLIM 表现不佳）。
- **基准选择偏差**：仅选取“Gurobi 10 分钟内找得到可行解但 60 分钟内无法证优”的实例，这偏向于 Gurobi 不是特别擅长的中等难度实例，不能代表所有竞赛实例。
- **实验环境限制**：未使用 GPU，也未说明 LLM 推理成本（虽然 LLM 仅离线使用，但仍需记录时间和资源）。
- **算法选择器较简单**：仅用随机森林回归，未对比更先进的自动算法选择（如 AutoFolio、SUNNY）或深度序列模型，算法选择的提升空间可能被低估。
- **超参数与配置空间局限**：仅考虑 30 种固定配置，未在更大配置空间内搜索，也未进行自适应动态调整。
- **无动态反馈**：图权重在搜索过程中固定，无法根据已有优化历史动态调整，可能浪费算力在重复优化同一局部区域。
