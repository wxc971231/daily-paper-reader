## 摘要
混合整数线性规划（MILP）是组合优化中的基础工具，具有广泛的现实应用。核心挑战之一是设计计算高效的MILP公式。大语言模型（LLM）为自动化建模过程提供了新的机会，从推导公式到强化公式。可靠的自动化需要稳健的方法来验证所提出的公式是否保留了底层优化问题。然而，现有方法仅仅是数值评估，无法对一般问题实例进行推理。我们通过引入一种可在Lean中形式化并进行机器检查的MILP重构的构造性定义来解决这一局限。我们开发了FLARE（公式级自动化重构评估），一种使用基于LLM的代理和Lean证明助手来验证提议的重构相对于参考公式是否正确的方法。为了评估我们的方法，我们引入了FormulationBench，一个包含20个问题和109个公式的具有挑战性的数据集。FLARE在FormulationBench的NP难子集上达到了100%的准确率，优于现有方法。此外，FLARE为其接受的每一个重构生成机器可检查的证书。对于不需要形式化保证的情况，我们引入了FLARE-NL，一种快速且廉价的LLM代理，其准确率与FLARE相当，但不产生证书。这些方法使得自动化优化建模中的可靠验证成为可能。

## Abstract
Mixed-Integer Linear Programming (MILP) is a fundamental tool for combinatorial optimization with extensive real-world applications. A central challenge is designing computationally efficient MILP formulations. Large Language Models (LLMs) offer new opportunities to automate the modeling process, from deriving formulations to strengthening them. Reliable automation requires robust methods for verifying that proposed formulations preserve the underlying optimization problem. However, existing approaches evaluate formulations numerically and fail to reason about general problem instances. We resolve this limitation by introducing a constructive definition of MILP reformulation that can be formalized in Lean and machine-checked. We develop FLARE (Formulation-Level Automated Reformulation Evaluation), a method that uses an LLM-based agent and the Lean proof assistant to verify proposed reformulations against a reference formulation. To evaluate our approach, we introduce FormulationBench, a challenging dataset of 20 problems and 109 formulations. FLARE outperforms existing methods, with 100% accuracy on the NP-hard subset of FormulationBench. Furthermore, FLARE produces a machine-checkable certificate for every reformulation it accepts. For cases where formal guarantees are not necessary, we introduce FLARE-NL, a fast and cheap LLM proxy that matches FLARE's accuracy but produces no certificate. These methods enable reliable verification in automated optimization modeling.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：混合整数线性规划（MILP）是组合优化中的基础工具，广泛应用于调度、规划、能源、芯片设计等领域。MILP 的核心难题之一是“问题公式化”（formulation）：如何将现实问题转化为数学建模。LLM 已展现出自动生成/改进 MILP 公式化的能力。
- **核心问题**：自动生成的公式化（尤其经过重构、切割平面等变换后）必须与原问题保持“等价”，即对所有可能的问题实例成立。现有验证方法几乎都是**实例级**（instance-level）的：比较单个实例上的最优目标值或解映射，无法保证对一般实例的正确性。
- **具体风险**：例如，EvoCut 提出的一些切割平面在实例级验证通过，却会删除某些实例的最优解；Ferchtandiker 等人的部分“等价重构”也存在错误或隐含假设。
- **解决目标**：实现**公式级**（formulation-level）验证——对所有问题实例都成立的可信保证，并借助形式化数学工具生成机器可检查的证明证书。

## 2. 提出的方法论

- **核心思想**：引入一种“构造性重构”（constructive reformulation）定义，并将其在 Lean 证明助手中形式化，再通过 LLM 智能体自动生成证明证书。
- **构造性重构定义（Definition 4.4）**：若 \(M'\) 是 \(M\) 的构造性重构，则存在一个四元组 \((\Phi_p, \Phi_{fwd}, \Phi_{bwd}, \Phi_{obj})\)：
  - **参数映射** \(\Phi_p\)：从原参数空间到新参数空间；
  - **前向映射** \(\Phi_{fwd}\)：将原可行域映射到新可行域；
  - **后向映射** \(\Phi_{bwd}\)：将新可行域映射回原可行域（要求多项式时间可计算）；
  - **目标映射** \(\Phi_{obj}\)：严格单调递增的实数函数。
  - 且满足：前向/后向可行性、目标保持（两个方向）、\(\Phi_{obj}\) 严格单调。
- **与现有定义的关系**：该定义强于 Audet 重构，也蕴涵实例级的 Quasi-Karp 等价；但它显式给出映射，大幅降低了自动化定理证明（ATP）的负担。
- **FLARE 工作流程**：
  1. 给定公式 A、B 及参数映射；
  2. 使用 Claude Code 等 agent harness，结合 Lean-LSP-MCP（模型上下文协议工具），将 A/B 与映射自动形式化为 Lean；
  3. 构造并证明 `MILPReformulation A B` 类型的定义；
  4. 最终验证证书不含 `sorry` 且不引入额外公理。
- **FLARE-NL**：不经过 Lean，直接以完整 prompt（包含定义、所有假设、参数映射）询问前沿推理 LLM，输出“是否重构”的结论；速度快、成本低，但无证书保证。

- **FLARE 与 FLARE-NL 在 FormulationBench 的 NP-hard 子集上均达到 100% 准确率**，显著优于 Execution（83.3%）和 EquivaMap（81.5%）。

- **成本/精度权衡**：FLARE-NL 比 FLARE 快约 30 倍、便宜约 25 倍，且精度相同，可作为初步筛选工具。

## 7. 优点

- **方法创新**：首次将 MILP 重构验证提升到公式级，并用形式化定理证明给出机器可验证证书。
- **定义设计巧妙**：构造性重构显式给出双向映射，比 Audet 定义更适合自动化证明，同时仍覆盖常见变换（如目标缩放、变量替换、切割平面）。
- **工程实践完善**：结合 Lean-LSP-MCP 和定制 agent skills，展示了通用 agent harness 在形式化数学中的可扩展性。
- **数据集质量高**：FormulationBench 包含详细的人工审计和 ground-truth Lean 证书，可作为后续研究的基准。
- **实用价值突出**：通过发现现有 LLM 工具生成的错误公式化，直接证明了实例级验证的危险性及其方法的必要性。

## 8. 不足与局限

- **无无效性证书**：FLARE 只能证明“是重构”，无法证明“不是重构”；失败不构成结论。
- **依赖形式化忠实性**：如果自动形式化偏离原公式，证书可能“证明”错误的命题；虽有审计，但无法完全杜绝。
- **假阴性风险**：LLM 可能因超时或证明能力不足而拒绝正确的重构，造成假阴性（附录 H 中 DeepSeek 模型出现此类失败）。
- **定义较强**：要求在整个可行域上建立双向可行映射和严格单调目标映射，可能排除合法的“最优解保持”型重构。
- **计算成本较高**：单条 FLARE 验证平均约 7 分钟、$1.18，最大 $8.02，不适合大规模应用。
- **实验覆盖不足**：仅限学术基准，未测试工业级大规模 MILP；FLARE 主实验无重复运行；多项式时间条件未被形式化在 Lean 证明义务中。
- **未来方向**：确定性形式化（如从 AMPL/MOI 自动翻译）、无效性证明、更弱的重构关系定义、以及集成到自动化建模管线（如先用 FLARE-NL 筛选再用 FLARE 认证）。
