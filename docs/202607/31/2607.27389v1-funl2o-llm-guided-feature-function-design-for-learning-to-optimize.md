## 摘要
学习优化（L2O）方法通过训练模型来预测解、热启动、分支决策或其他形式的求解器指导，从而加速重复优化。这些流程中一个关键却常被忽视的组成部分是特征函数，它将问题实例映射为机器学习模型的输入。现有的L2O方法通常依赖手工设计的特征，使得表示设计是手动的，并且在不同领域间基本固定。我们提出了FunL2O，这是第一个通过LLM驱动的程序演化来自动化L2O特征设计的统一框架。在FunSearch风格的循环中，LLM提出可执行的特征函数，而固定的评估过程则重新训练原始L2O模型并衡量下游优化性能。我们在涉及解预测和热启动的线性和二次规划任务，以及使用GNN引导的后门分支和预测-搜索的混合整数优化任务上评估了FunL2O。在连续和离散优化任务以及四种LLM中，演化出的特征始终优于手工设计的表示。这些结果确立了LLM驱动的特征演化作为自动化L2O表示设计的一种通用且有效的方法。

## Abstract
Learning-to-optimize (L2O) methods accelerate repeated optimization by training models to predict solutions, warm starts, branching decisions, or other forms of solver guidance. A critical yet largely overlooked component of these pipelines is the feature function that maps problem instances to inputs for machine learning models. Existing L2O methods typically rely on hand-crafted features, making representation design manual and largely fixed across domains. We introduce FunL2O, the first unified framework for automating feature design through LLM-driven program evolution for L2O. In a FunSearch-style loop, an LLM proposes executable feature functions, while a fixed evaluation process retrains the original L2O model and measures downstream optimization performance. We evaluate FunL2O on linear and quadratic programming tasks involving solution prediction and warm-starting, as well as on mixed-integer optimization tasks using GNN-guided backdoor branching and Predict-and-Search. Across continuous and discrete optimization tasks and four LLMs, the evolved features consistently outperform hand-crafted representations. These results establish LLM-driven feature evolution as a general and effective approach to automating representation design in L2O.

## 1. 核心问题与整体含义

- **研究背景**：学习优化（L2O）方法利用神经网络在重复求解相同结构、不同数值的优化问题中加速求解过程。L2O管线通常包括特征函数 φ、学习模型 M 和下游求解器 S，其中特征函数决定模型看到什么信息以及信息如何结构化。
- **核心问题**：现有 L2O 方法几乎都依赖手工设计的特征函数，表示设计过程繁琐、跨域固定，成为自动化管线中的瓶颈。即使模型架构、训练目标、求解器接口不断改进，输入表示却被默认固定，很少被系统搜索和优化。
- **整体含义**：该论文提出 **FunL2O**，首次将 LLM 驱动的程序演化引入 L2O 特征设计，将“如何表示优化实例”从手工决定转为自动化搜索。该框架通过 FunSearch 风格循环让 LLM 提出可执行特征函数，并用完整 L2O 管线重训与下游性能评估来筛选最优表示，从而统一并自动化 L2O 的表示设计。

## 2. 方法论

### 2.1 核心思想

- 将特征函数设计视为**程序搜索问题**：在原始 L2O 管线中，仅替换特征函数，其余部分（模型架构、损失函数、训练计划、数据、求解器、预测目标）全部固定。
- 每个候选特征函数经过**语义契约验证**后，重新训练模型，并在验证集上测量其下游优化性能，测量结果用于指导下一轮搜索。这一过程是 L2O-in-the-loop 的。

### 2.2 关键技术细节

- **语义契约** \(C_P = (U_P, Z_P, I_P, V_P)\)：
  - \(U_P\)：部署时可用的实例字段或求解器状态；
  - \(Z_P\)：输出类型、张量方向、最大特征宽度；
  - \(I_P\)：需满足的不变量（确定性、有限输出、保留手工通道）；
  - \(V_P\)：静态与动态验证器。
- **标准化提示模板**：提示包含共享指令、语义契约、特征词汇表、当前精英程序及测量结果，并要求 LLM 返回可执行代码。LLM 不接触验证实例、目标解或测试结果，只依据验证性能反馈。
- **搜索流程**：
  1. 手工特征函数作为初始基线和第一个有效示例；
  2. 每代生成 6 个候选程序，经过验证和修复（最多 3 次修复）；
  3. 通过验证的候选独立训练并评估，更新搜索记忆；
  4. 按排名键选择 Top-2 精英程序进入下一轮提示；
  5. 搜索结束后返回验证集上最优函数，在独立测试集上评估。
- **排名机制**：\(\rho_P(\phi) = (b_P, v_P, q_P)\)，按字典序排序。先看可行性条件是否满足，再看不可行度，最后看目标质量或求解工作量；符号设定保证越低越好。
- **常见候选形式**：追加式特征 \(\phi(x) = \text{Concat}(\phi_0(x), \psi(x))\)，保留原始手工通道，并叠加新提出的特征。

### 2.3 公式（文字说明）

- 特征函数：\(\phi: X_P \to Z_P(d_\phi)\)，将实例映射为宽度为 \(d_\phi\) 的表示；
- 模型输出：\(z_\phi(x) = \phi(x)\)，\(a_\phi(x) = M_{\theta^*_\phi}(z_\phi(x))\)；
- 下游结果：\(y_\phi(x) = S_P(x, a_\phi(x))\)；
- 每个候选需重训：\(\theta^*_\phi = \text{Train}_P(\phi; D_{tr})\)；
- 测量结果：\(m_P(\phi) = \text{Agg}_{x \in D_{val}} \mu_P(x, y_\phi(x))\)；
- 最终目标：\(\phi^* \in \arg\min_{\phi \in \Phi_P} \rho_P(\phi)\)。

## 9. 总体评价与适用建议

- **总体定位**：FunL2O 并非一个免配置的端到端自动优化系统，而是一个“离线搜索 + 在线部署”可分离的框架。其核心贡献是验证了“LLM 提出特征程序 + 完整 L2O 管线评估”这一范式在多个问题域中的有效性，将表示设计纳入自动搜索范畴。
- **适用场景**：最适合反复求解同一分布、同一结构优化问题的生产环境，如调度、组合拍卖、网络设计等。此时离线搜索成本可以被后续大量求解任务摊薄，部署阶段也不引入额外推理开销。
- **方法可迁移性**：语义契约与验证器机制不仅适用于 L2O 特征设计，也可推广到其他“输入表示影响下游学习性能”的管线中，例如数据增强策略、策略网络状态编码、图神经网络特征工程等，具有一定的通用方法论价值。

## 10. 对后续研究的启示

- **降低评估成本**：当前每轮搜索都需要完整重训一个模型，未来可探索代理损失、早停、迁移初始化等方式，减少 L2O-in-the-loop 的评估开销。
- **扩展搜索空间**：可将特征搜索与模型架构、损失函数、求解器决策联合搜索，实现真正全自动的 L2O 管线定制。
- **提升跨域泛化**：研究如何让搜索记忆跨数据集、跨问题类型复用，减少重复搜索成本。
- **建立特征可解释性分析工具**：论文已展示可读程序的价值，后续可进一步发展自动化分析手段，从演化结果中归纳领域规律，反向指导优化理论。

总体而言，FunL2O 是一项方法贡献与实证研究并重的论文，实验设计严谨、控制全面，结论清晰且不过度声称；尽管成本较高、依赖人工契约设定，但在目标场景下具有较强的实用潜力与扩展空间。
