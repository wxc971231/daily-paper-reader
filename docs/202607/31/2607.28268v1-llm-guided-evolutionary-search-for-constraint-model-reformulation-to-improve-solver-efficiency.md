## 摘要
组合问题大量出现在工业应用中。一种常见的方法是将这些问题表示为声明式约束模型，随后可将其编译并由一系列后端求解器求解。近期研究表明，大型语言模型（LLMs）可以从自然语言生成正确的模型，但即使模型正确，其求解代价也可能很高，因为性能对建模选择仍然敏感。在这项工作中，我们研究LLMs能否自动进行面向性能的模型重构。受自动启发式设计（AHD）的启发，我们采用了一个进化框架，其中LLM提出候选重构方案，这些方案经过验证并与用户定义的基线模型进行基准比较。我们比较了适用于AHD的搜索策略，这些策略控制哪些先前的尝试、指令和实测反馈进入每个提示。现有的保留策略优先考虑最近性或性能，但并未明确多样化上下文。为弥补这一空白，我们引入了行为特征多样化保留（PDR），它将最大边际相关性（MMR）应用于实例级运行时向量，以保留行为上多样化的尝试。我们使用基于验证的最终模型选择，在八个CSPLib问题上系统地评估这些策略。结果表明：（i）迭代重构能产生显著的留出集加速；（ii）保持保留上下文多样化的策略优于仅保留最近或最快尝试的策略；（iii）基于验证的选择能改善每种策略的留出集加速。

## Abstract
Combinatorial problems appear in numerous industrial applications. A common approach is to formulate these problems as declarative constraint models that can subsequently be compiled to and solved by a range of back-end solvers. Recent work shows that Large Language Models (LLMs) can produce correct models from natural language, but even a correct model can be expensive to solve because performance remains sensitive to modelling choices. In this work, we investigate whether LLMs can automate performance-oriented model reformulation. Inspired by Automatic Heuristic Design (AHD), we use an evolutionary framework in which an LLM proposes candidate reformulations that are verified and benchmarked against the user-defined baseline model. We compare AHD-adapted search strategies that control which prior attempts, instructions, and measured feedback enter each prompt. Existing retention strategies prioritize recency or performance, but do not explicitly diversify the context. To cover this gap, we introduce Profile-Diverse Retention (PDR), which applies Maximal Marginal Relevance (MMR) to instance-level runtime vectors to retain behaviourally diverse attempts. We systematically evaluate the strategies on eight CSPLib problems using validation-based final model selection. The results show that: (i) iterative reformulation can produce substantial held-out speedups; (ii) strategies that keep the retained context diverse outperform those that retain only recent or the fastest attempts; and (iii) validation-based selection improves the held-out speedup of every strategy.

- **背景衔接**：传统上模型重构依赖专家手工调整（如切换视角、添加隐含约束、打破对称性等），既有自动方法多基于预定义规则目录或流线化约束（streamliner），难以实现全局重构。最近兴起的自动启发式设计（AHD）范式已被证明能利用LLM通过进化搜索自动生成编程启发式，本文将这一范式迁移到声明式约束模型重构领域。
- **整体含义**：论文回答了一个重要问题——LLM能否在进化反馈循环中，迭代地重构出比用户基线性求解更快的等效模型，并且如何选择历史上下文以最大化搜索效率。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 总体框架：迭代 LLM 引导重构（算法1）
- 从用户基线模型 B 出发，在训练实例集 D_tr 上测量其运行时间。
- 每轮迭代：搜索策略 σ 从历史 H 中选出上下文 R_t 与指令 o_t → 构建提示 → LLM 返回候选模型 m_t 与理由 ρ_t → 评估器检查候选解是否有效（相对于 B）并测算每个实例的运行时间 → 更新历史。
- 搜索结束后，在验证集 D_val 上筛选所有历史最优模型（incumbents），返回总时间最小者作为最终模型。
- 时间超出上限的用 PAR2 惩罚（计为两倍时限）。

### 解有效性定义（Definition 1）
- 候选模型 m 在实例集 S 上返回的解必须能被基线模型 B 接受（通过将候选答案固定到基线决策变量上检测可行性），从而允许候选模型采用不同视角和编码而不失正确性。

### 关键策略（表1）
- **基线策略**：Sampling（无历史上下文）、Full-history（保留全部历史，超长则丢弃最旧）。
- **基于最近/质量**：Last-k（最近 k 次尝试）、Top-k（训练时间最快的 k 个有效尝试）、Hybrid（两者并集）。
- **EoH（启发式进化）**：维护最多 K=5 个有效模型族群，批量生成候选；使用4种算符指令（完全新方法 e1、组合扩展 e2、局部结构修改 m1、求解器组件修改 m2）；父代按总训练时间逆概率抽样；变量 e2 研究是否附带测量反馈。
- **PDR（Profile-Diverse Retention，行为特征多样化保留）**——本论文核心创新：
  - 将每个候选模型表示为一个实例级运行时向量，经对数变换并按实例归一化得到行为轮廓 p_t,d(m)；
  - 用 RMSE 距离度量两个模型行为差异；
  - 用 MMR（Maximal Marginal Relevance）框架：先保留最快模型，然后迭代加入质量与多样性加权最大的候选（λ=0.5 平衡两者），直到保留 k=5 个。
  - PDR warm-start 变体：前 2k 轮无上下文、之后切换到 PDR。

## 6. 论文的主要结论与发现

- **RQ1（有效性）**：进化式 LLM 重构确实能产生大幅留出加速——240次运行中144次返回比基线更快的模型，无一返回无效或不正确（UNSAT）结果；所有策略的GM加速均>1×（1.55×–2.26×），PDR 最高（2.26×）。
- **RQ2（策略比较）**：保持上下文多样性的策略（PDR、EoH+反馈、Sampling）优于仅保留最近（Last-1）或最快（Top-1）的策略；PDR 比纯质量 Top-5 提升 1.30×；给 EoH 加入测量反馈平均提升 1.13×；PDR warm-start 反而变差（-1.37×）。
- **RQ3（验证选择）**：基于验证集的最终模型选择（而非直接返回训练最优者）**改善了所有策略**的留出加速，并能过滤过度拟合训练实例的候选。
- **vs 流线化**：整体模型重构（PDR 2.26×、EoH+反馈 2.04×）大幅优于 StreamLLM-single（1.02×），在全部8个问题上占优。
- **模式归纳**：成功重构大多使用领域认可的建模技术——变量视角切换、表格约束、对称性打破、全局基数约束、隐含约束、以及覆盖数组中的流线化前缀固定。
