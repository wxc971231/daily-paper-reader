## 摘要
车辆路径问题（VRPs）是基础性组合优化问题，在各种场景中有着广泛的应用。先进的优化求解器可以有效解决此类问题。然而，为求解器建模复杂VRP变体通常需要大量的领域专业知识，这限制了先进优化技术的可及性。在本文中，我们提出了强化学习增强的LLM智能体（RLEA），一种旨在自动化建模复杂VRP的多智能体框架。RLEA引入了一个使用Soft Q-learning训练的轻量级神经规划器，以高效协调基于LLM的智能体的行动。此外，我们为该系统的配备了进化记忆模块和检索增强生成，使得智能体在生成和改进程序以解决VRP时，能够利用积累的经验和外部求解器知识。我们在多种求解器上评估了48个不同的VRP变体。实验结果表明，RLEA优于先前的最先进方法，成功率提高了16.67%，同时显著减少了运行时错误。这些结果验证了将强化学习与基于LLM的推理相结合对于自动化优化建模非常有效。附录可在以下网址获取：https://doi.org/10.5281/zenodo.19134435。

## Abstract
Vehicle Routing Problems (VRPs) are fundamental combinatorial optimization problems with widespread applications in various scenarios. The advanced optimization solvers can effectively solve such problems. However, modeling complex VRP variants for solvers often requires substantial domain expertise, which limits the accessibility of advanced optimization technologies. In this paper, we propose Reinforcement Learning Enhanced LLMAgents(RLEA), a multi-agent framework designed to automate the modeling of complex VRPs. RLEA introduces a lightweight neural Planner trained with Soft Q-learning to efficiently orchestrate the actions of LLM-based agents. In addition, we equip the system with an evolutionary memory module and retrieval-augmented generation, enabling the agent to leverage both accumulated experience and external solver knowledge during program generation and refinement for solving VRPs. We evaluated 48 distinct VRP variants across various solvers. The experimental results demonstrate that RLEA outperforms the previous state-of-the-ar method, achieving a 16.67% higher success rate while significantly reducing runtime errors. These results validate that integrating reinforcement learning with LLM-based reasoning is highly effective for automated optimization modeling. ## 2. 论文提出的方法论

### 2.1 总体架构

RLEA 是一个多智能体框架，包含三个核心组件：

1. **Planner（规划器）**：轻量级神经网络（冻结小语言模型 Qwen2.5-1.5B-Instruct 编码 + 两层 MLP Q 网络头），负责按当前状态选择动作；
2. **Executor（执行器）**：由 LLM（默认 DeepSeek-Reasoner）充当，执行 Planner 所选动作，完成代码生成或修正；
3. **Memory（记忆模块）**：由 Collector 与 Memory Distiller 两个 LLM agent 组成，负责从交互轨迹中提炼、沉淀成功经验和失败教训供后续复用。

### 2.2 动作空间设计

论文定义了三个动作，构成 Planner 的动作空间 A = {Refine, RAG, MLEM}：

- **Refine（ar）**：利用 LLM 自纠错能力，对当前代码进行检查、诊断和迭代修正，使程序满足全部约束；
- **RAG（ag）**：将问题拆解为原子约束集合 C = Φ_decomp(P)，再以每个约束为查询，依据平方欧氏距离检索外部求解器文档（如 Python 代码示例），由 LLM 筛选与汇总后生成或修正代码；
- **MLEM（am，Meta-Learning with Evolved Memory）**：从记忆池 M 中基于语义余弦相似度检索 top-K 条历史成功与失败经验作为上下文样本（in-context demonstrations），帮助模型在同一场景下快速适配新约束。前两者可视为“外部知识记忆”，MLEM 则是“内部演化经验记忆”。

### 2.3 训练阶段（Soft Q-learning）

- 任务被建模为带记忆池的 MDP：⟨S, A, P, R, γ, M⟩；
- 策略由 **soft Q-network** 诱导，动作选择服从 **Boltzmann 分布**：
  - πθ(a|s) = exp(Qθ(s,a)/α) / Σ_{a'∈A} exp(Qθ(s,a')/α)
- **奖励函数**基于最优度差距 δt 设计：若得到可行解，则 rt = 1/(1+δt)；否则 rt = 0（奖励值在 (0,1] 内，越接近最优解则越大）；
- 训练使用 soft Bellman residual，TD target 包含熵正则项；
- 优化器为 Adam（学习率 1e-4），replay buffer 容量 512，batch size 16，折扣因子 γ = 0.99，熵温度系数 α = 4，目标网络每 4 步硬拷贝更新，每 episode 上限 16 步；
- 记忆演化与策略优化并行进行：replay buffer B 用于 RL 更新；记忆池 M 单独维护，供 MLEM 使用。

### 2.4 推理阶段

- Planner 参数冻结，对问题进行前向传播，按学到的策略依次选择动作，指导 Executor 执行代码生成与修订；

1. **RLEA 在 OR-Tools 上显著领先**：SR 达 **62.50%**，相比 SOTA 方法 DRoC（45.83%）**提高了 16.67 个百分点**；RER 从 27.08% 降至 **16.67%**，下降约 10.41 个百分点。

6. **迭代次数存在最优区间**：T_max 从 3 增至 6 时 SR 从 34.15% 提至 62.50%，RER 由 43.90% 降至 16.67%；超过 6 后增量收益趋缓，继续增加迭代次数基本是无用功。

### 9. 结论与展望

#### 9.1 核心结论

- 自动化 VRP 建模可以通过 “多智能体 + 记忆增强 + 强化规划” 的架构取得显著进步，RLEA 在 OR-Tools 上 62.50% 的成功率表明该方向仍有上升空间，且方法本身并不依赖超大参数模型，具备部署可行性。

#### 9.2 对未来工作的启示

1. **扩展动作空间与状态表示**：未来可引入更细粒度的建模动作，例如“变量定义修正”“约束类型识别”“求解参数重配置”等，并结合问题结构 embedding，使 Planner 拥有更强的过程控制能力。
2. **动态与随机 VRP 的延伸验证**：需要将当前静态约束组合推广到随机需求、实时路况、动态插入订单等更贴近实际供应链的场景，以检验记忆泛化能力在时间演化型问题上的边界。
3. **记忆质量的可解释性控制**：建议对记忆蒸馏设置质量门槛，区分正负样本的采样比例，并对记忆检索的敏感度进行系统消融——这将帮助社区判断经验记忆的贡献中哪些来自检索机制、哪些来自知识内容本身。
4. **方法论的外推潜力**：本文的思路可迁移至除 VRP 外的其他运筹优化任务（如排产调度、资源分配、网络设计），形成一个“自然语言 → 求解器代码”的通用自动化范式。

#### 9.3 一句话总结

RLEA 是一项推进“LLM + 运筹优化”交叉研究方向的工作：通过将强化学习嵌入多智能体记忆增强框架，它有效缓解了 LLM 求解器自动化建模中推理成本高、经验复用弱的痛点，系统验证了轻量策略规划与 LLM 执行的协同可行性，为后续研究提供了坚实的基线参照与方法论启示。虽然当前绝对成功率仍未臻完善，且评测集中于静态、确定性的 VRP 族，但其模块化的设计思想与细致的对比实验拆解，使其成为该领域值得关注与延伸的重要工作。
