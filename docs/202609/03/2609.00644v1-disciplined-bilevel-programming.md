## 摘要
双层优化为分层决策问题提供了一种自然的建模语言。然而，应用现有的数值求解器通常需要大量的手动分析和重构。在本文中，我们引入了规范化双层规划（DBLP），这是一个符号化框架，允许用户以接近数学公式的高级、人类可读的方式指定和求解乐观双层问题。对于具有规范化非线性上层问题和满足规范化参数化规划规则的凸下层问题，DBLP自动将下层问题规范化为锥形式，并利用锥卡鲁什-库恩-塔克条件构建等价的单层重构。我们松弛了所得的互补约束，并使用间隙延续过程来近似求解一系列光滑非线性问题。我们在开源Python包BLVPY中实现了DBLP，这是CVXPY的双层规划扩展。我们在一系列来自多个应用领域的双层优化问题上展示了BLVPY的建模和求解能力。所提出的框架和实现允许用户用几行代码指定和求解双层优化问题，而无需先前具备双层建模和数值优化的专业知识。

## Abstract
Bilevel optimization provides a natural modeling language for hierarchical decision problems. However, applying existing numerical solvers usually requires substantial manual analysis and reformulation. In this paper, we introduce disciplined bilevel programming (DBLP), a symbolic framework that allows users to specify and solve optimistic bilevel problems in a high-level, human-readable way that is close to the mathematical formulation. For problems with a disciplined nonlinear upper problem and a convex lower problem satisfying the disciplined parameterized programming rules, DBLP automatically canonicalizes the lower problem into conic form and constructs an equivalent single-level reformulation using the conic Karush-Kuhn-Tucker conditions. We relax the resulting complementarity constraint and use a gap continuation procedure to approximately solve a sequence of smooth nonlinear problems. We implement DBLP in the open-source Python package BLVPY, an extension of CVXPY for bilevel programming. We demonstrate the modeling and solution capabilities of BLVPY on a range of bilevel optimization problems from several application domains. The proposed framework and implementation allow users to specify and solve bilevel optimization problems within a few lines of code, without prior expertise in bilevel modeling and numerical optimization.

## 2. 论文提出的方法论

### 2.1 核心思想

DBLP 将“规范化优化”理念扩展到双层规划：

- 上层问题必须满足 **DNLP（Disciplined Nonlinear Programming）** 规则；
- 下层问题必须满足 **DPP（Disciplined Parameterized Programming）** 规则，并是一个以 \(x\) 为参数、以 \(z\) 为变量的凸优化问题。

满足上述条件后，系统可以自动将问题转换为标准单层优化问题。

### 2.2 关键技术细节

**下层问题锥形式规范化。**

一个 DPP 兼容的凸下层问题会被自动写成如下标准锥形式：

\[
\min \; c(x)^T u + d(x)
\]
\[
\text{s.t.} \quad A(x)u + s = b(x), \quad s \in \mathcal{K}
\]

其中 \(\mathcal{K}\) 是若干正常锥的笛卡尔积。由于 DPP 的性质，从参数 \(x\) 到规范数据 \(c(x), A(x), b(x)\) 的映射是仿射的。

**KKT 条件与单层重构。**

在若干标准假定（连续性、无损规范化、Slater条件等）下，下层最优性等价于锥 KKT 条件：

\[
y=\rho(u),\quad A(x)u+s=b(x)
\]
\[
A(x)^T\lambda+c(x)=0,\quad s\in\mathcal{K},\;\lambda\in\mathcal{K}^*,\;\lambda^T s=0
\]

由此可将原始双层问题等价写成单层问题。但精确互补约束 \(\lambda^T s=0\) 会破坏常规非线性规划的约束规范条件，因此直接求解通常困难。

**互补松弛与 gap continuation（间隙延续）。**

- 将精确互补条件松弛为：

  \[
  \lambda^T s \le \epsilon
  \]

- 对每个 \(\epsilon>0\) 得到一个平滑非线性规划；
- 利用命题 4.1，任何松弛可行点都会给出下层目标次优性上界：

  \[
  0 \le f_0(x,\rho(u)) - p^\star(x) \le \lambda^T s \le \epsilon
  \]

- 若下层目标强凸，还可进一步得到解距离界：

  \[
  \|\rho(u)-y^\star(x)\|_2 \le \sqrt{\frac{2\epsilon}{\mu}}
  \]

- 算法流程是：从较大的 \(\epsilon\) 开始，用当前解作为下一个更小 \(\epsilon\) 问题的热启动初值，按比例逐步缩减 \(\epsilon\)，直到达到目标容差。

**BLVPY 实现管线。**

- 开源 Python 包 BLVPY 基于 CVXPY 扩展实现；
- 当前版本支持下层可精确规范化为 LP 或 SOCP 的问题；
- 管线包括：
  1. 审计式规范化与仿射映射提取；
  2. 初始提升点构造；
  3. gap continuation 求解；
  4. 独立残差验证与诊断输出。

## 8. 缺点与局限性

- **问题类别的内在限制**：DBLP 仅支持“上层 DNLP + 下层 DPP 凸”的问题。对于下层非凸（如整数规划、非凸非线性规划），或下层含参数化锥约束时不可表达为 DPP 的情况，框架无法处理。
- **缺乏全局最优性保证**：单层重构后的非线性规划通常非凸，求解器仅能保证找到局部最优解或平稳点。优化上层目标时，可能错过全局最优的上层决策。
- **KKT 等价性依赖强假设**：包括下层问题的约束规范条件（如 Slater 条件）、解的适当正则性等。在退化情形或约束规范不满足时，KKT 条件可能不成立，框架的正确性缺乏保障。
- **对上层目标与约束的限制不够明确**：论文声称支持 DNLP，但并未讨论上层目标非光滑、上层存在互补约束或上层可行域非凸等特殊情况下的理论后果，用户仍需自行保证问题的规范化合法性。
- **可扩展性存疑**：锥形式下 \(A(x), b(x), c(x)\) 的维度随下层变量与约束规模增长，单层重构引入的互补变量与松弛变量会显著增大非线性规划规模；当下层规模较大（如成千上万个变量）时，求解效率可能迅速恶化。
- **数值实验规模与对比不足**：所有示例均为中小规模合成算例，缺乏大规模问题上的扩展性实证；且没有与 BilevelJuMP、PAO、或专门的全局优化双层求解器进行横向对比，也缺少多次随机实验下的统计稳定性报告。
- **gap continuation 的容差设置依赖用户经验**：\(\epsilon\) 的初始值、递减比例、终止容差等参数需要用户指定，文中未给出系统的调参策略或对不同参数的敏感性分析。
